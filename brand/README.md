# Materi Merek Trimegah

Letakkan brand guideline dan aset merek di folder ini.

## Yang dibutuhkan

- Panduan merek (PDF) — nilai warna, tipografi, aturan logo
- Logo SVG versi terang dan gelap
- Berkas font, bila berlisensi khusus

## Setelah berkas masuk

Isi token `--tri-*` pada `docs/06-DESIGN.md §2.0`, lalu hapus catatan
"menunggu brand guideline" di sana.

Periksa kontras setiap pasangan warna merek dengan teks di atasnya:
minimal 4,5:1. Bila warna resmi tidak memenuhi, pakai varian gelapnya
untuk latar teks dan catat penyimpangan itu — jangan menurunkan ambang.

## Catatan
